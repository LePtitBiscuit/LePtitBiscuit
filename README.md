## À propos

- Je construis des applications web **full-stack TypeScript** : du front Vue/Nuxt jusqu'à l'API, la base de données et le déploiement.
- J'aime l'infra propre : conteneurs, reverse proxy, provisioning automatisé, CI/CD, migrations de données.
- Projet open source : [**Graphinity**](https://github.com/LePtitBiscuit/Graphinity) ([documentation](https://leptitbiscuit.github.io/Graphinity/))
- Sous Linux (Fedora + Hyprland) au quotidien.
